# TodoList

> HTML, CSS, JavaScript를 공부하며 직접 만들어 쓰는 개인 할 일 관리 앱

---

## 기능

- ✅ 할 일 추가 / 완료 / 삭제 / 수정 / 순서 변경
- ✅ 카테고리 분류 및 필터
- ✅ 마감일 설정 / 기간 초과 표시 / 날짜순 정렬
- ✅ 완료 상태 필터
- ✅ 데이터 영속성 (localStorage)
- ✅ 두 가지 테마
  - **Hacker** — 터미널 / Matrix 스타일
  - **BOJ** — 백준 온라인 저지 스타일
- ✅ PWA 지원

---

## 기술 스택

| 항목 | 내용 |
|------|------|
| 언어 | HTML / CSS / JavaScript (Vanilla) |
| 저장소 | localStorage |
| 배포 | GitHub Pages |
| PWA | manifest.json + Service Worker |
